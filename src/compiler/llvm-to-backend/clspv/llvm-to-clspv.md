# LLVM To CLSPV

The llvm-to-clspv tool takes the LLVM IR generated by the SSCP generic
compiler and passes it through the `clspv` tool to generate Vulkan
flavor SPIR-V.

The tool generates SPIR-V version 1.3 for the `GroupNonUniform` capability,
and propagates the max push constant and uniform buffer sizes from the
Vulkan physical device.

## Passes

The following LLVM passes are run after adding them to the pass manager in the
same order. These are to ensure that clspv can consume the LLVM IR and are
run at the *Optimize Flavoured IR* stage of the pipeline.

A major challenge in the implementation is making this part of the compilation
flow less brittle so users can reliably run their kernels.
